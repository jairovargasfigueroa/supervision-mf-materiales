# ERP · Microfrontend Materiales: qué hace

## Pantallas

| Pantalla | Quién | Caso de uso | Etapa |
|---|---|---|---|
| Catálogo de materiales (lista, alta, edición) | Administración | Gestionar materiales | Base |
| Stock mínimo por obra | Administración | Gestionar materiales | Base |
| Stock por obra (estado bajo, justo, ok) | Residente, gerente | Consultar obra | Base |
| Consumos: usado frente a previsto por partida | Residente, gerente | Consultar obra | Base |
| Órdenes de compra generadas | Administración | Automatización | Capa 2 |

Referencia visual: el prototipo HTML de la carpeta general.

## Qué no hace

- No registra ingresos ni salidas (eso se hace desde la app de obra).
